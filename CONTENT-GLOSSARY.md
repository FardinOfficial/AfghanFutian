Central terminology reference for English, Afghan Pashto (`ps`) and Afghan Dari (`fa-AF`). All three locales must use these forms unless the owner or a native reviewer approves a change. This file is the single place to resolve wording before editing dictionaries, metadata, forms or email copy.

## Editorial rules

- Describe **methods and coordination**, never owned vessels, aircraft, warehouses, fleets, certifications, licences, founding dates, staff counts, client counts, shipment volumes or guaranteed routes.
- Distinguish Afghan Futian's work from work performed by suppliers, carriers and partner facilities. Use “partner-operated” rather than implying ownership.
- Use trade language: specification, quantity, target price, packaging, destination, supplier reply, sample, quotation, export document, carrier booking, handover, tracking.
- No generic AI phrasing: avoid “seamless”, “world-class”, “unparalleled”, “transforming the future”, “one-stop solution” and their Pashto/Dari equivalents.
- Use Persian/Arabic script punctuation (`،`, `؟`, `.`) and correct word spacing. Insert ZWNJ (`U+200C`) in Persian/Pashto compound words where a suffix or prefix attaches to a non-joining letter (for example Dari `تأمین\u200Cکننده`, `اداره\u200Cمیشود`). Do not leave English words inside Pashto/Dari copy unless they are proper names or official product names.
- Brand transliterations currently in use: Pashto `افغان فوټیان`, Dari `افغان فوتین`. These remain pending owner/native confirmation and must be consistent inside each locale.

## Terms deliberately avoided

| Avoid | Use instead | Reason |
| --- | --- | --- |
| `سکرول` / `پیمایش` in body copy | scrolling context only when needed; omit otherwise | Prior native-review item. |
| `ورودي` / `خروجي` | `داخلي` / `بیروني` or explicit `واردات` / `صادرات` | Ambiguous in Pashto trade copy. |
| `مقر` for the Yiwu base | `مرکز` | `مقر` implies a formal office classification not published. |
| `شتمنۍ` for assets/facilities | `اسناد`/`امکانات` only when confirmed; otherwise omit | Implies owned assets. |
| `بازارگاه` | `بازار` / `بازارونه` | Non-native in Afghan Dari. |
| `تلرانس` | `تحمل` or `زغم` | Prior native-review item. |
| `جهت هنری` | omit; no design-direction claim is published | Unsupported. |
| `آزادسازی` | `خوشه کول` / `رهایی` only in customs context | Ambiguous. |
| `تحویل و تحول` | `تحویل` | Redundant in Afghan Dari. |
